Description of Service

Vault-Sync is a free, open-source plugin that synchronizes your Obsidian vault files with cloud storage services. All sync operations occur directly between your local device and your cloud storage account. The Plugin provides an authentication proxy hosted on Cloudflare Pages solely for facilitating the OAuth login process; no vault data passes through this proxy.

The Plugin includes configurable conflict resolution strategies (smart merge, create copies, keep this device, keep cloud), background transfer for large files, and functions that keep and restore deleted files and past versions.

User Responsibilities

  • Authentication: By default, the Plugin uses a developer-provided authentication proxy for OAuth login. Alternatively, you may configure your own Google Cloud Project with OAuth credentials (Client ID / Client Secret) or a custom authentication proxy.
  • Data Backup: You are responsible for maintaining backups of your vault data. While the Plugin is designed for reliable synchronization, no software can guarantee zero data loss.
  • Credential Security: You must keep your OAuth Client Secret confidential. Do not share it with others.

サービスの内容

Vault-Syncは、ObsidianのVaultファイルをクラウドストレージサービスと同期する無料のオープンソースプラグインです。全同期処理はローカルデバイスとクラウドストレージ間で直接実行されます。本プラグインはOAuthログインプロセスを仲介するための認証プロキシをCloudflare Pages上でホストしていますが、Vaultデータがこのプロキシを経由することはありません。

本プラグインには、設定可能な競合解決戦略（スマートマージ、コピーを作成、本端末を優先、クラウドを優先）、大容量ファイルのバックグラウンド転送機能、および削除ファイルと過去の版の保管・復元機能が含まれます。
