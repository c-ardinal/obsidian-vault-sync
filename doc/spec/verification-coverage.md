# 検証範囲（アドオン用 Vault 変換と複数端末）

アドオン用 Vault 変換（以下「変換」）に関する検証の保証範囲と非保証範囲を記載する。記載のない組合せは未検証として扱う。

## 1. 検証手段

| 手段 | 対象 | 実コード | 端末数 |
| --- | --- | --- | --- |
| 2〜4 端末シミュレーション（`tests/sim/addon-conversion.test.ts`、16 件） | SyncManager、MigrationService、GoogleDriveAdapter | 使用（クラウドと暗号処理は擬似実装） | 2 または 4 |
| 変換中の他端末編集（`tests/tests/code-scenario/migration-concurrent-edits.test.ts`、21 件） | MigrationService | 使用（他端末はクラウドへの直接書込で代用） | 1 + 擬似 1 |
| 形式模型（`formal/tla/Migration.tla`） | 変換手順と他端末の同期の全交錯 | 不使用（模型） | 変換端末 + 他 1 台（ファイル 2 件）、変換端末 + 他 2 台（ファイル 1 件） |
| 乱数シミュレーション（`tests/sim/multi-device.sim.test.ts` 他） | 通常同期（変換なし） | 使用 | 2〜3 |

## 2. 保証範囲（上記手段で検証済み）

| 項目 | 手段 |
| --- | --- |
| 稼働中の他端末が、変換後の最初の同期で変換を検出して停止（手動同期、無変更のタイマー同期） | シミュレーション、形式模型 |
| 検出時点の通知と導入画面・解除画面の表示要求（アドオン導入済み、未導入） | シミュレーション |
| 解除前の端末は変換後 Vault へ一切送信しない | シミュレーション |
| 変換後 Vault 内の全ファイルが暗号化済み（平文混入なし、「(2)」改名なし） | シミュレーション、形式模型 |
| 旧フォルダの状態 3 種（移行ロックあり、ロックなし、削除済み）での追従 | シミュレーション |
| 追従前の編集の保持（未編集は他端末の内容を採用、双方編集は両方を保持） | シミュレーション、形式模型 |
| 変換後 Vault で削除済みのノートは追従時に復活しない。追従前に編集済みの場合は編集を優先 | シミュレーション、形式模型 |
| 追従前に新規作成したノートは削除扱いにせず送信 | シミュレーション、形式模型 |
| 4 端末混在（変換端末、稼働中・導入済み、稼働中・未導入、停止中でオフライン編集あり）での収束。変換後のパスワード変更、再ロック、改名、削除を含む | シミュレーション（2 件） |
| 変換中・交換直前に他端末が旧フォルダへ送信した編集と削除の保持 | 形式模型、変換中の他端末編集テスト |
| 他端末不在時の旧フォルダ即時削除、存在時の保持と通知 | 変換中の他端末編集テスト |

## 3. 非保証範囲（未検証・既知の不具合）

| 項目 | 状態 |
| --- | --- |
| 実 Google Drive での動作（変更フィードの遅延・順序、検索の結果整合性、ID 指定操作の権限、容量・レート制限） | 未検証。擬似サーバーは即時整合で、実サービスとの差異は検出不可能 |
| 実アドオン（実暗号処理、実ダイアログ）と実 Obsidian 上での変換 | 未検証。CI の実 Obsidian 検査は導入・設定画面のみ対象 |
| 5 台以上、および 4 端末で上記 2 件以外の順序・組合せ | 未検証。4 端末は固定手順 2 件のみで、乱数探索なし |
| 形式模型の 3 台構成はファイル 1 件・版数 4 まで。改名、フォルダ操作、アドオン未導入、パスワード変更、再ロックは模型の対象外 | 模型化なし |
| 交換直前に旧フォルダへ遅延送信されたノートを、追従後 1 時間以内（旧フォルダ削除前）に変換後 Vault で削除した場合、旧フォルダの後処理で 1 回復活する | **既知の不具合（未修正）**。形式模型 `MigrationLateDelete` が反例を提示。消失・破損はなし |
| 変換の同時実行（2 端末が同時に変換を開始） | 未検証。移行ロックの確認と作成の間に比較交換なし |
| 変換中の変換端末の強制終了と再開を、他端末の同期と組合せた場合 | 未検証（単独端末での中断・再開のみ既存テストあり） |
| クラウド上での Vault フォルダの手動改名・削除・復元 | 未検証 |
| モバイル（Android、iOS）固有の動作（バックグラウンド停止、ファイル名制約）と変換の組合せ | 未検証 |
| 0.19.2 以前の版と 0.19.3 の混在（旧版端末は追従処理なし） | 対象外。全端末の更新が前提 |
| 変換後 Vault の `conversion-base.json` が欠落・破損した場合 | 削除判定を行わず、従来動作（ノート復活）へ縮退。破損時の動作は単体テストなし |
| 保存済みパスワードによる自動解除の失敗経路（他端末でのパスワード変更後の再起動） | 未検証（`main.ts` の処理で、テスト対象外） |
