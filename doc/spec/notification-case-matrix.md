# 通知表示詳細マトリックス

## 1. 重要エラー通知 (通知レベル非依存)

以下の通知は通知レベル設定(詳細/標準/エラーのみ)に**依存せず、常に表示される**。
同期失敗の原因をユーザが認知できなければ問題の解決が不可能なため、全レベルで表示を保証する。

`executeSmartSync` の catch ブロックでエラー種別を判定し、適切な通知キーを選択する:

| エラー種別         | 判定条件                                                   | 通知キー                  |
| :----------------- | :--------------------------------------------------------- | :------------------------ |
| 認証エラー         | "Not authenticated" / "Authentication failed" を包含       | `noticeSyncFailedAuth`    |
| ネットワークエラー | "Network error" / "Failed to fetch" / "unreachable" を包含 | `noticeSyncFailedNetwork` |
| その他のエラー     | 上記以外                                                   | `noticeSyncFailed`        |

| 通知の種類                                                             | 初回同期 | 起動時同期 | 手動同期 | タイマー同期 | 保存時同期 | 編集時同期 | レイアウト変更時同期 | フルスキャン |
| :--------------------------------------------------------------------- | :------: | :--------: | :------: | :----------: | :--------: | :--------: | :------------------: | :----------: |
| `❌ [同期] 未認証です。設定画面からログインしてください。`             |   表示   |    表示    |   表示   |     表示     |    表示    |    表示    |         表示         |     表示     |
| `❌ [同期] ネットワークエラー。接続を確認して再試行してください。` |   表示   |    表示    |   表示   |     表示     |    表示    |    表示    |         表示         |     表示     |
| `❌ [同期] 同期失敗: {0}`                                              |   表示   |    表示    |   表示   |     表示     |    表示    |    表示    |         表示         |     表示     |

加えて、利用者の対処が必要な以下の通知も、通知レベル「エラーのみ」で表示を保証する（各トリガーでの表示可否は2章の表に準拠）。

| 通知キー                                                                  | 理由                                                                     |
| :------------------------------------------------------------------------ | :----------------------------------------------------------------------- |
| `noticeConflictSaved` / `noticeConflictRemoteSaved` / `noticeCheckOtherDevice` | 競合ファイルは同期対象外で他デバイスから不可視。本通知が唯一の認知手段 |
| `noticeAddonRequired` / `noticeAddonUpdateRequired` / `noticeEngineVerifyFailed` / `noticeVaultLocked` | 利用者の操作まで同期が停止する状態                                       |
| `noticeNameNotSupported` | 本端末のOS（Windows / Android）で使用不可能なファイル名のクラウド上ファイルは本端末に未保存。本通知が唯一の認知手段（ファイル単位で起動中1回のみ） |

`noticeConflictSaved` は手動消去まで表示を継続し、押下で競合ファイルを表示する。

手動同期とフルスキャンでは、同期前のリモート確認（アドオン使用有無の確認）が失敗した際も、上記の判定条件で選択した通知を表示する。自動トリガーでは直後に再試行されるため、ログ記録のみとする。

**実装:** `notification-matrix.ts` の `ALWAYS_SHOW` セットに登録。`shouldShowNotification` で通知レベルが「エラーのみ」でもこのセットに該当するキーはバイパスされる。

## 2. ケース別表示マトリックス (通知レベル依存)

`表示`: ユーザへ通知する
`非表示`: ユーザへ通知しない(ログには記録する)
`-`: No care

- 手動同期・フルスキャン: ユーザーの明示的操作のため、毎回表示する
